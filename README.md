# NVIDIA (NVDA) 최근 1개월 주식 대시보드

> **안내:** 본 프로젝트는 **AI 초안**이며, **2026-11-20 미국 장 마감 기준 저장 자료**를 바탕으로 제작된 정적 웹 대시보드입니다. **실시간 시세가 아니며 투자 권유가 아닙니다.**

## 포함 파일 (공개 대상)
- `index.html`: 대시보드 메인 페이지 (HTML · CSS · JavaScript 단일 구조)
- `data/nvda_1m_2026-11-20.json`: 2026-10-21 ~ 2026-11-20 일별 종가, 기업 개요, 관련 뉴스 저장 자료

## 주요 기능
- **정보 구분:** 모든 내용을 `사실` / `AI 해석` / `미확인 / 확인 필요` 배지로 구분
- **핵심 요약 우선:** `핵심 사실`과 `쉬운 해석`을 나란히 배치한 입문자용 1분 요약
- **종가 차트 & 표:** 23거래일 일별 종가 인터랙티브 SVG 차트(호버·터치 툴팁, 이벤트 마커) 및 일별 종가 표 토글
- **관련 뉴스 (최대 5건):** 원문 링크 및 본문 확인 여부 표시 (`HTTP 200` 요약 / `HTTP 401` 접근 불가 구분)
- **3종 화면 스타일 토글:** `토스`(기본) · `다크 글래스` · `NVIDIA` 시그니처 테마 전환
- **인쇄 / PDF 저장:** A4 인쇄 전용 레이아웃(`@media print`) 지원

## 출처
- 일별 종가 (2026-10-21 ~ 2026-11-20, USD): StockAnalysis
- 11/18 ~ 11/20 시가·고가·저가·거래량 및 52주 범위: Investing.com, The Motley Fool
- 기업 개요·공시·뉴스: NVIDIA IR, NVIDIA Newsroom, The Guardian, The Motley Fool, Reuters(제목·날짜·링크만 확인)

## 로컬에서 열기
```powershell
python -m http.server 8765 --bind 127.0.0.1
```
실행 후 브라우저에서 `http://127.0.0.1:8765/index.html`로 접속하거나 `index.html`을 직접 엽니다.
